# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues.

Use GitHub's **Security** tab and select **Report a vulnerability** to open a private security advisory. Include the affected version or commit, reproduction steps, potential impact, and any suggested mitigation.

Do not include real credentials, private user information, vessel locations, or production data in a report. Use synthetic examples.

## Supported version

Security fixes target the current `main` branch. This community release does not guarantee support for older snapshots or third-party deployments.
