# Contributing

Contributions are welcome through GitHub issues and pull requests.

- Use synthetic data only.
- Never commit credentials, production configuration, private vessel information, or precise real-world user locations.
- Add or update tests for behavioral changes.
- Run `php artisan test` before opening a pull request.
- Keep marine safety limitations explicit; do not present supplementary data as certified navigation or official warning information.

By contributing, you agree that your contribution is licensed under AGPL-3.0-only.
